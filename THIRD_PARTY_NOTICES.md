# Third-party reference

The head-tracked off-axis projection method and projection derivation are adapted
from the technique demonstrated by **TheParallaxView**, by Peder Norrby /
ALGOMYSTIC AB:

- https://github.com/algomystic/TheParallaxView
- https://github.com/algomystic/TheParallaxView/blob/master/Assets/Scripts/OffAxisProjection.cs
- https://github.com/algomystic/TheParallaxView/blob/master/LICENSE

The original repository licenses its code under MIT and its artwork separately.
ParallaxKit includes no artwork, scenes, Unity dependencies, or trademarks from
that repository. Its native projection uses Metal reverse depth instead of the
original Unity matrix's depth mapping. The original code notice is retained below.
